# Atlas Histórico da América do Sul (1493–2026)

Mapa interativo da América do Sul com uma linha do tempo de 1493 a 2026. As cores do mapa mostram impérios, reinos, colônias e repúblicas, e um painel lateral traz as principais mudanças e fatos históricos de cada período.

Abra `index.html` no navegador ou acesse a versão publicada no GitHub Pages.

Fronteiras aproximadas, construídas a partir dos dados do Natural Earth (domínio público).
